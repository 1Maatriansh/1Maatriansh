## `04 — my approach`

I don't really want to build another website that looks like:

```text
┌─────────────────────────────┐
│       HERO SECTION          │
│                             │
│   BIG TEXT                  │
│   BUTTON                    │
│                             │
│   3 FEATURE CARDS           │
│                             │
│   FOOTER                    │
└─────────────────────────────┘
```

I like interfaces with a little more personality.

**Minimal ≠ empty.**

**Simple ≠ boring.**

**Interactive ≠ over-animated.**

The goal is to make something people actually want to explore.
